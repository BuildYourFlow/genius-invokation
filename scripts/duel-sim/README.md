# Duel simulation experiment

Research harness for a reproducible, seat-balanced comparison of two Genius Invokation TCG v7.0 deck share codes using the repository's real `@gi-tcg/core` engine and `@gi-tcg/data` definitions.

The harness is intentionally deck-agnostic: both seats use the same policy implementation. Results, technical errors, seeds and blind-judge inputs are written under `results/duel-sim/`.
